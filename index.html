Contenedores e imágenes

Descargar una imagenpull, bajar, descargar
docker pull node:18
Crear y arrancar en un pasorun, levantar, iniciar
docker run -d --name <nombre> -p 3000:3000 <imagen>
Ver qué está corriendolistar, ps
docker ps
Ver todos (también detenidos)listar, ps all
docker ps -a
Arrancar / detener unostart, stop, parar
docker start <nombre>
docker stop <nombre>
Borrar un contenedorrm, eliminar
docker rm -f <nombre>
Ver las imágenes que tengolistar imágenes
docker images
Borrar una imagenrmi, eliminar imagen
docker image rm <imagen>:<tag>
Construir mi imagenbuild, Dockerfile
docker build -t miapp:1 .

Depurar y compose

Ver los logs en vivologs, follow, watch, consola
docker logs -f <nombre>
Entrar al contenedorexec, terminal, shell, navegar
docker exec -it <nombre> sh
Ver IP, volúmenes, variablesinspect, detalles
docker inspect <nombre>
Levantar todo el proyectocompose up, levantar set
docker compose up -d
Levantar reconstruyendorebuild, cambios de código
docker compose up --build
Levantar el compose de desarrollocompose custom, -f, dev
docker compose -f docker-compose-dev.yml up
Bajar todocompose down, apagar
docker compose down
Bajar todo y borrar datosdown volúmenes, reset db
docker compose down -v
Liberar espacio en discoprune, limpiar, borrar todo
docker system prune

Redes y volúmenes

Crear una rednetwork create
docker network create mired
Listar redesnetwork ls list
docker network ls
Crear contenedor en una red--network, conectar
docker create --name monguito --network mired mongo
Listar volúmenesvolume ls, datos
docker volume ls
Persistir datos de Mongovolumen, -v, persistencia
docker run -d -v mongo-data:/data/db mongo

Conexión app → base de datos

Connection string de Mongomongoose, conectar, host, authSource
mongodb://<user>:<password>@monguito:27017/miapp?authSource=admin
Abrir la consola de Mongomongosh, shell db
docker exec -it monguito mongosh -u <user> -p <password>
